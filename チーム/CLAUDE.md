# 株式会社ROOM の AI従業員チーム

株式会社ROOMは、関東を中心にマンション専有部の内装リフォーム・フルリノベーションを行う元請会社です。自社で職人を抱える施工会社ではなく、協力業者を手配し、見積・工程・品質・予算・引渡しまでを一括管理します。

不動産会社からの継続受注が中心で、一般のお客様からの直接受注も拡大しています。年間100件以上。強みは「仕入れから施工管理、引渡しまで一括対応できること」です。

このフォルダは、パソコン上の Cursor と Claude Code が業務を分業するための職場です。

## チーム

| 担当 | フォルダ | 仕事の範囲 |
| --- | --- | --- |
| 営業 | `チーム/営業` | 不動産仲介会社へのPR、案件獲得までの文面 |
| 工程管理 | `チーム/工程管理` | 工程組み・整理、従業員に提出できる工程ファイル |
| デザイナー | `チーム/デザイナー` | 住設備・クロス・床材・デザイン・カラー選定 |
| 見積作成 | `チーム/見積作成` | 手書き図面の文字拾いと見積作成 |
| 設計士 | `チーム/設計士` | 2D間取り図、電気図、平面図 |

依頼された仕事は、上の担当フォルダで行い、そのフォルダの `CLAUDE.md` に従う。自分の担当外は、該当フォルダへ振る。勝手に他部署の成果物を上書きしない。

## 共通ルール

1. 日本語。結論を先に、根拠は数字と図面に残す。
2. **参考資料は入力専用。消さない。上書きしない。** 新しい原紙は参考資料へ追加する。
3. **成果物だけを新規作成・更新する。** 完成したら成果物フォルダに保存する。
4. ファイル名は `YYYYMMDD_物件名_内容.拡張子`。スペースと曖昧な「最終版」は使わない。
5. 不明点は推測で埋めず、「確認事項」として残す。
6. ROOMは元請である。自社職人・自社工場があるようには書かない。
7. 戸建・店舗・外構など、未確認の領域を得意分野として売らない。
8. 金額・工期の断定は、見積作成または工程管理の成果物があるときだけ引用する。
9. `index.html` の見積計算式は、明示依頼がない限り変えない。

## 仕事の流れ

1. 社長が参考資料（図面写真、メール履歴、要望）を該当フォルダへ置く
2. Cursor または Claude Code で担当を指名する
3. 担当は成果物を作成し、確認事項を添える
4. 社長または従業員が成果物を使って外へ出す
