# パソコンで ROOM の AI従業員を動かす

株式会社ROOMの AI従業員は、**担当フォルダ**と **Cursor / Claude Code** の組み合わせです。

## フォルダ

```
チーム/
  営業/        参考資料  成果物  CLAUDE.md
  工程管理/    参考資料  成果物  CLAUDE.md
  デザイナー/  参考資料  成果物  CLAUDE.md
  見積作成/    参考資料  成果物  CLAUDE.md
  設計士/      参考資料  成果物  CLAUDE.md
```

原紙（手書き図面、仲介会社リスト、要望）は各担当の `参考資料` へ置く。AIが出す提出物は `成果物` へ保存される。

## 1. Cursor

1. [Cursor](https://cursor.com) を入れる
2. この `room-manager` フォルダを開く
3. Agent で担当を指名する

例：

```
見積作成として、チーム/見積作成/参考資料 の手書き図面から文字を拾い、
見積を チーム/見積作成/成果物 に作って。読めない文字は確認事項にして。
```

## 2. Claude Code

```bash
npm install -g @anthropic-ai/claude-code
cd room-manager
claude
```

起動後の例：

```
営業として、仲介会社向けPRメールを チーム/営業/成果物 に書いて
```

```
/daily-briefing
```

```
/review-estimate
```

## 3. 手書き図面から見積まで

1. 図面写真を `チーム/見積作成/参考資料` に入れる
2. Cursor または Claude Code で見積作成に拾い出しと見積を頼む
3. 間取りが必要なら同じ図を `チーム/設計士/参考資料` にも置き、設計士へ振る
4. 色と設備はデザイナー、工期は工程管理、仲介への一文は営業

## うまく動かないとき

- 担当がルールを知らない → その担当フォルダの `CLAUDE.md` を @ で付ける
- 図面を読んでくれない → 参考資料にファイルがあるか、チャットに画像を付ける
- 空の成果物フォルダ → まだ提出物が無いだけ。Git には各フォルダの `CLAUDE.md` が入っている
