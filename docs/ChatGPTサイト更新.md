https://room-project-profit.daiki199607210721.chatgpt.site/

このURLは ChatGPT ログインが必要なため、GitHub 側から直接は上書きできません。ChatGPT でサイトを開いて、下の文を Edit に貼ってください。

## ChatGPT に貼る文

```
@Sites 既存サイト https://room-project-profit.daiki199607210721.chatgpt.site/ を更新してください。

目的：既存の ROOM Project Profit（案件・見積・粗利・単価）はそのまま残し、株式会社ROOMのAI従業員をアプリに取り込む。

必ず守ること
- 既存の見積計算式は変えない
- 既存の案件保存・ダッシュボードは残す
- 元請である。自社職人がいるようには書かない
- 読めない寸法は埋めない。図に無い工事は足さない
- 売価は税込。粗利は税抜売上 − 総原価。25%未満は要見直し

追加するタブ「AI社員」
担当は次の5人だけ。
1. 営業：不動産仲介会社へのPRメール、案件獲得まで。価格・工期は断定しない
2. 工程管理：工程組み、従業員が提出できる工程表。着工日が無ければ仮と書く
3. デザイナー：住設備・クロス・床材・デザイン・カラー選定。無い品番は作らない
4. 見積作成：手書き図面の文字拾いと見積。いまの案件入力を拾い出しに使う
5. 設計士：2D間取り図、電気図、平面図。無い寸法は描き足さない

画面の動き
- ダッシュに「この案件で全員実行」を置く
- 各担当に「この案件で実行」と「参考メモ」
- 成果物を画面に表示し、コピーとダウンロードができる
- 設計士は間取りの簡易図を出す

会社の事実
関東のマンション専有部リフォーム・フルリノベの元請。協力業者を手配し、見積・工程・品質・予算・引渡しまで一括。年間100件以上。不動産会社の継続受注が中心。

正とする実装は GitHub リポジトリ daiki199607210721-source/room-manager の index.html です。そのAI社員タブと同じ動きにして、更新をこのサイトにデプロイしてください。
```
